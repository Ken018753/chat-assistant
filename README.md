## ✨ Features

- 🎯 **11 scenarios** — Reject, thank, apologize, request leave, confess, negotiate, comfort, and more
- 👥 **8 relationships** — Boss, colleague, client, friend, date, family, elders, acquaintances — each with custom phrasing strategies
- 🎨 **4 reply styles** — Formal / Humorous / Tactful / Direct
- 💬 **Reads the context** — Paste recent messages for replies that *actually* fit the conversation
- 📋 **One-click copy** — Generate, copy, paste — done in 3 seconds
- 📚 **Reply history** — Save your favorites, reuse them anytime
